Text tasks in Excel tests

Splitting a full name into first and last name, or building a code from several columns, shows up in admin, HR and data-entry assessments.

First name

=LEFT(C2,FIND(" ",C2)-1). FIND returns the position of the space, and LEFT takes everything before it. In Excel 365 =TEXTBEFORE(C2," ") does the same.

Last name

=RIGHT(C6,LEN(C6)-FIND(" ",C6)). The length of the name minus the position of the space gives the number of characters to take from the right.

Joining text

The & operator joins values: =UPPER(B2)&"-"&A2 turns East and 1001 into EAST-1001. CONCAT and TEXTJOIN work too.
